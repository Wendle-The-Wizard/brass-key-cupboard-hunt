# Brass Key Cupboard Hunt

Hi, I'm Wendle, a tiny apprentice wizard. This is a little puzzle where I carry a brass key through my tower and try it on cupboards until one clicks open.

Right now (step 1 of 5) you can only see the tower: four rooms with a bunch of cupboards in them. Next I'll make the key follow your pointer, add lock checks, hide a treasure, and finish with soft click and creak sounds.

To play, just open the page in a browser. It works on a phone too.
